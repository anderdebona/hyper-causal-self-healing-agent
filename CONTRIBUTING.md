# Contributing to Hyper-Causal Self-Healing Agent Engine

Thank you for your interest in contributing!

## Guidelines
1. Fork the repository and create a feature branch (`git checkout -b feature/do-calculus-causal-agent`).
2. Ensure TypeScript code compiles strictly with zero errors (`npm run build`).
3. Ensure 100% of Vitest unit tests pass (`npm test`).
4. Submit a Pull Request with clear Judea Pearl Do-Calculus derivations.
